- HTML
- CSS
- Docker
- GitHub Pages

## Docker Çalıştırma Komutları:
```bash
docker build -t webproje .
docker run -d -p 8080:80 webproje
```

## Projenin Kısa Açıklaması:
Bu proje, Bulut Bilişim dersi kapsamında Docker container mantığını kavramak ve GitHub Pages üzerinden web sayfası yayınlamak amacıyla hazırlanmıştır.
